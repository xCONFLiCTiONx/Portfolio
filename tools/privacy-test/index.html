💡 How to Test xPrivacyGuard (Paused vs. Running)

Use this page to verify that xPrivacyGuard is actively sinkholing domains at the Android local VpnService layer.

🟢 1. Testing with App RUNNING

When xPrivacyGuard is enabled, expected Block Rate is 90%–100%. Ad servers, tracker domains, and DoH bypass hosts (e.g. dns.google) will return NXDOMAIN or fail instantaneously.

🟡 2. Testing with App PAUSED

When protection is paused in xPrivacyGuard, requests pass through without interception. Expected Block Rate is 0%–15% (unless another network resolver blocks them).

🏢 3. Cloudflare Zero Trust Integration

xPrivacyGuard routes DNS to your configured Zero Trust endpoints (e.g. 172.64.36.1 / e0uvvv2ul3.cloudflare-gateway.com). Check the matrix above to confirm Zero Trust status.
