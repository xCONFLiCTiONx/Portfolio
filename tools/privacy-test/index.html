    💡 How to Test xPrivacyGuard (Paused vs. Running)

    Use this page to verify that xPrivacyGuard is actively sinkholing domains at the Android local VpnService layer.

    🟢 1. Testing with App RUNNING

    When xPrivacyGuard is enabled, expected Grade is A+ or A (Score 85–100). Ad servers, tracker domains, and DoH bypass hosts (e.g. dns.google) will return NXDOMAIN / Sinkhole instantaneously.

    🟡 2. Testing with App PAUSED

    When protection is paused in xPrivacyGuard, requests pass through without interception. Expected Grade is F or D (Score 0–40).

    🏢 3. Cloudflare Zero Trust Integration

    xPrivacyGuard routes DNS to your configured Zero Trust endpoints (e.g. security.cloudflare-gateway.com). Check the matrix above to confirm Zero Trust status.
