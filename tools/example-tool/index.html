Framework Integration Guide

To create a new tool in this portfolio:

  1. Copy /tools/example-tool/ to /tools/my-tool/.
  2. Customize index.html, tool.js, and tool.css.
  3. Add a tool entry in /portfolio.config.json under the tools array.
  4. Configure layout controls (header, sidebar, footer) as booleans.
  5. Deploy! The tool automatically registers on the Tools page.
