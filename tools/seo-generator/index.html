The crawler reads HTML directly into browser memory using fetch(); it does not require downloading pages. Run this tool from your own site for same-origin access, or let the crawler fallback to CORS proxies for cross-origin URLs. Link crawling cannot discover orphan pages that are not linked; sitemap URLs are also used as discovery seeds when available.
